## 📖 About

This website documents my first internship — a 6-week program by the **1M1B Foundation** focused on sustainability, climate action, and Applied AI. The portal serves as my personal journal, progress tracker, and program reference — all in one place.

## 🚀 How It Works

1. Open the site on **any device** — phone, laptop, anywhere
2. Go to **My Journal** tab
3. Tick tasks as you complete them — **saves instantly** to Firebase
4. Write notes in the textarea — **auto-saves** after 1.5 seconds
5. Click **"📋 All Notes (Overview)"** to see all your notes across all 6 weeks
6. Firebase keeps everything in sync — no manual export needed
